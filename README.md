# 藏点本事 · FavToSkill

<img src="public/brand/app-icon-192.png" width="96" alt="藏点本事 App Logo" />

**让收藏，变成本事。**

藏点本事（FavToSkill）是一款面向跨平台收藏场景的 AI 原生知识管理与能力转化工具。

它帮助用户整理小红书、抖音、B站等场景中的知识内容，通过 AI 摘要、来源检索与对话式 Skill 创建，将零散信息转化为可理解、可查找、可复用的个人知识。

> 当前提供可在本机运行的单用户 Web 原型，预设了一套演示模板。站外分享与灵动岛通过 Web 模拟；真实导入、语义检索及原生能力的具体范围见下文。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 轻量导入 | 演示分享接收、解析状态、归类回执与撤回；真实文本及抖音文案导入提供后端预览/确认接口 |
| 智能知识库 | 分类与收藏管理、AI 分类概览、单篇摘要和重点解析；原文与 AI 结果分开呈现 |
| AI 一键整理 | 提供归类、精确重复保留、有重复依据的分类合并及原文更新建议；逐项选择、确认应用、整体撤回 |
| 智能问答 | 基于收藏原文检索回答，支持全库、分类及单篇范围，展示可查看的来源引用 |
| Skill 创建 | 在同一对话中澄清目标、确认引用、生成并自动保存；支持编辑、试用及 ZIP 导出 |
| 可重复演示 | 恢复预设资料，重新准备未分类、重复收藏和资料更新场景；支持电脑上的手机比例展示 |

## 核心体验

**收藏 → 整理 → 理解 → 复用**

1. **收藏：** 在分享模拟中体验收录，也可通过后端接口预览并保存文本资料。
2. **整理：** 查看 AI 建议，选择归类、重复保留或原文更新，核对后再应用。
3. **理解：** 用自然语言提问，结合摘要、原文和来源引用回看知识。
4. **复用：** 在统一对话中将相关收藏转化为 Skill，按任务试用、修改并导出。

Skill 导出包包含 `SKILL.md`、`skill.json`、引用原文及许可说明，不包含密钥或图片/视频；在外部工具中的兼容性需分别验证。

## 设计理念

**轻巧、有趣、有秩序的个人知识工具。**

采用暖白、深墨色与青柠绿的品牌视觉体系，以「80% 简洁克制 + 20% 品牌趣味」为原则。以收藏内容为主角，让 AI 自然融入操作流程。

知识库与「我的 Skill」通过顶部双导航切换，底部统一 AI 对话承担问答、目标澄清和 Skill 创建。移动端优先，兼顾安全区域、键盘避让与电脑展示。

## 快速运行

需要 **Node.js 22.13+**，推荐 Node.js 24。首次运行（PowerShell）：

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

已有 `.env` 时保留原配置，不要重复覆盖。前端与 API 会一起启动：

| 入口 | 地址 |
| --- | --- |
| 个人知识库 | [打开个人库](http://127.0.0.1:5173/) |
| 预设演示模板 | [打开演示库](http://127.0.0.1:5173/?workspace=demo#knowledge) |
| 电脑展示手机比例 | [打开手机演示](http://127.0.0.1:5173/?workspace=demo&presentation=phone#knowledge) |
| 站外分享模拟 | [打开分享演示](http://127.0.0.1:5173/?workspace=demo#share-demo) |
| API 健康检查 | [检查 API](http://127.0.0.1:3001/api/health) |

以上地址仅在本机服务启动后可用，GitHub 仓库本身不托管可运行的完整应用。

## 演示方式

项目预设了一套演示模板，初始包含 **7 个分类、36 条收藏、35 张封面和18个预设 Skill**。演示库与个人库分别持久化，普通浏览器刷新保留修改。

- **真实 AI：** 在服务端 `.env` 设置 `AI_API_KEY`、`AI_MODEL`、`AI_BASE_URL`，重启后端。演示库默认也使用真实模型；模型未配置或调用失败时明确报错，不回退为模拟成功。服务设置支持查看配置和检测连接，完整说明见 [AI_SETUP](docs/AI_SETUP.md)。
- **离线演示：** 在演示库服务设置中明确选择离线模式，规则/模板结果标注“未调用模型”。无需密钥即可体验知识管理、整理示例和预设 Skill。
- **重新体验：** 顶栏齿轮 →「刷新演示数据」→ 确认。恢复预设收藏及 Skill，重新准备归类、重复与模拟更新场景。会替换演示库中的新增/修改资料，个人库和密钥不变；历史对话保留，旧的自建资料引用可能失效。完成提示支持撤回，后续写入仍受版本保护。
- **手机比例：** 在电脑中以390×844展示同一应用，可切换大屏/紧凑尺寸、随窗口缩放，也可返回桌面版；不代表原生 App 或真机验收。
- **分享模拟：** 在模拟抖音页中点击分享 →「藏点本事」，体验后台接收、解析阶段、归类回执、详情和撤回。解析文字及初始归类为预设，收录结果实际保存至演示库。当前交付不含未完成的 MP4，缺少视频时展示封面。

## 当前实现边界

| 能力 | 当前范围 |
| --- | --- |
| 跨平台导入 | 分享界面为 Web 模拟。真实文本及 TikHub 抖音文案导入已有后端接口，尚未接通前端真实导入入口；小红书/B站真实采集未接入 |
| 语义检索 | 已实现可选 Embeddings 分支，需配置并联调；未配置时使用关键词与原文片段检索，不宣称已启用语义检索 |
| 重复与分类合并 | 根据相同原文或链接等明确证据提出建议；不支持语义近似去重或融合多篇原文 |
| 原文更新 | 支持手动补充 → 新旧内容预览 → 确认替换 → 撤回；TikHub 来源支持主动检查帖子文案更新，需配置服务且尚未真实联调。不会自动定时抓取或重写关联 Skill |
| 多模态与系统能力 | 未实现视频 ASR、图片 OCR、原生系统分享及真实灵动岛 |
| 对话与生成 | 使用真实结果后的段落渐入，未实现 Token 流式；历史保留文本与来源，交互卡片状态尚未完整跨刷新恢复 |
| 部署 | 当前为本机单用户，无账号鉴权；公网使用前需补用户隔离、限流、备份与 HTTPS 等部署能力 |

详细能力、接口及后续工作见 [BACKEND_STATUS](docs/BACKEND_STATUS.md)。`GET /api/capabilities`（演示库 `/api/demo/capabilities`）只报告配置与能力状态，不发起付费探测。

## 开发与验证

```powershell
npm run typecheck
npm test
npm run build
npm run start:api
```

`build` 包含前后端类型检查、前端构建、后端编译及种子素材复制。`start:api` 启动编译后的 API；`dist/` 为前端构建目录，需另行托管。分离部署前设置 `VITE_API_BASE_URL`，后端通过 `WEB_ORIGIN` 配置允许的前端来源。

自动化测试覆盖导入预览/确认、知识管理、来源检索、Skill 创建/试用/导出、整理事务与撤回、演示重置及原文更新。模型 HTTP 测试使用受控返回验证协议和数据链路，不等同于线上模型效果验收。

需要无密钥、无个人数据的隔离环境时，可运行 `npx tsx scripts/demo-sandbox.ts`，使用5174/3002端口与纯内存数据库，关闭后丢弃。日常个人库与演示库保存在被 Git 忽略的 `data/`，`.env`、数据库、依赖和未完成视频不纳入交付。
