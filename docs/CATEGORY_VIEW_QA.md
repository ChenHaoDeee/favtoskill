# 分类浏览优化记录

2026-10-18，依据用户最新分类页示意与四项修改要求。

## 实现
- 分类页使用独立sticky标题栏，返回按钮、当前分类名称及搜索；隐藏双导航及演示配置横幅。返回首页恢复知识库/Skill双导航。仅分类页改变导航结构，单篇/Skill详情沿用现有结构。
- 分类摘要直接展示：从当前已保存资料的标签提取主题，过滤明显活动/推广标签；没有标签时回退到资料标题。显示实际条目数量，空分类显示空状态。它是资料概览，不标注AI生成，也不触发Skill创建。
- 知识卡片使用白底、圆角，标题最多两行，底部单独显示来源平台；片段完整性说明保留在单篇详情。
- 用户确认演示资料来自抖音，固定种子及生成脚本同步sourcePlatform；已有库仅迁移“旧项目演示资料”的来源字段，保留标题/归类/其他来源修改。旧GitHub provenance及“未核验原帖”的详情说明继续保留，不表示链接解析已经实现。
- 分类标题栏加入对话背景隔离选择范围，半屏/全屏对话的背景锁滚动与焦点约束继续有效。
