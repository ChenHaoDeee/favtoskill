## 打开与操作

运行 `npm run dev` 后打开 http://127.0.0.1:5173/?workspace=demo#knowledge 。原入口显示个人库，并有进入演示库的链接。

演示库默认使用真实 AI。预设收藏仅代表资料来源是演示数据，不代表模型也被模拟；问答、归类、Skill 创建/修改/试运行均按真实模型流程执行。

顶部可主动选择“离线演示（不调用模型）”。仅在明确选择离线时使用规则/模板，模型未配置或调用失败不会自动降级。旧版默认规则模式的本地设置不再沿用。

推荐体验路径：
1. 进入科技分类，打开一条收藏，查看保存的文字稿及来源说明。
2. 底部 AI 提问“AI生图中的关键词联想陷阱怎么处理？”，查看相关摘录和来源卡片。
3. 在同一对话表达创建Skill目标；模糊时在问题卡选择方向或自填，点击确定后继续。
4. 在引用卡增删并确认资料，生成后自动保存，结果卡可进入详情编辑定义；通过详情底部对话输入任务试用。
5. 详情黑色导出Skill按钮一次下载ZIP，内含Markdown、JSON、所选资料原文、来源和许可。
6. 回到“我的 Skill”，刷新后仍能找到新建项目；详情也可调整、试运行和导出。
7. 首页“AI 整理”查看真实重复记录；没有明确调整建议时显示无需调整。收藏详情可编辑标题、标签和分类，分类可增改移除。删除和应用整理均经过确认，最近一次操作可在15秒提示期间撤回；出现更新后的操作会被版本保护拒绝撤回。

## 实现范围

- 知识库管理：分类 CRUD、收藏标题/标签/归类修改、详情、软删除和版本保护撤回。
- 整理：规则或模型提出方案、用户可调整/忽略、确认应用，过期方案拒绝提交。当前支持归类预览、重复组保留项选择和有重复内容证据的分类合并；后两者默认不选择且需二次确认，支持整体撤回。子分类未实现。
- 对话：保存原文分块检索、引用、追问上下文、历史与新对话。可配置 Embeddings，未配置时仅关键词检索，不宣称语义检索上线。
- Skill：统一对话内目标澄清、引用选择、生成、字段编辑、自然语言调整、保存、文本试运行及导出。演示模式自然语言调整保留为用户要求，实际语义重写需真实模型。外部依赖不满足时阻止执行。
- 唤醒：重复提示、相关新增资料更新建议、基于已有使用记录的闲置主题回顾，可关闭且不自动修改数据。现支持预设资料的站外分享导入演示；真实帖子解析仍延期。
- 当前演示 Skill 的引用是按原文件主题关联的起始材料，不表示已经逐条验证每个方法与每条来源的充分对应。
