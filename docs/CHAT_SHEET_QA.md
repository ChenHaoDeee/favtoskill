# 全局AI面板交互验证

2026-10-18，根据用户默认入口与半屏参考图调整。

## 实现

- ChatPanel保留两态的输入值和业务处理；默认只读输入框点击后展开、不触发键盘，随后焦点落在关闭按钮。用户再点击面板内输入框后可编辑。
- 默认输入框和面板输入框共享composer样式、64px高度、最大720px宽、相同底部safe-area锚点。半屏面板底部固定，拖动只改变上边缘；展开采用clip-path自下而上揭示，避免把输入框随transform移动。
- slider手柄用Pointer Capture实现鼠标/触摸拖动，限制最小/最大高度；支持方向键64px调整、Home最小、End全屏。原历史、新对话、全屏和关闭均保留。
- 背景锁滚动、inert、Esc与Tab焦点约束沿用；手柄加入焦点序列。Skill创建仍使用统一面板，创建表单阶段隐藏普通对话输入。
- 欢迎区使用既有透明星星IP；快捷提问改为中性色双列，点击仍先填入输入框，发送后进入既有业务。
- VisualViewport键盘状态提升面板到可视区域、输入框留在键盘上方。全屏安全区由手柄容器承接，避免顶栏重复加安全区。

## 实测记录

- 手机390×844：默认/半屏输入框均x=12、y=768、w=351、h=64；打开焦点为关闭按钮，不自动聚焦编辑框。
- 实际拖动手柄从y=424到280，面板432→576px，输入框y仍768；方向下键再变512px。展开全屏height844px，输入框y仍768。
- 快捷总结填入并发送，取得真实演示资料摘录及引用；历史列表可进入已有消息，新对话清空当前显示，创建Skill进入目标澄清流程。
- 聚焦输入框后把可视高度缩到500px：keyboard=true，面板底部500px，输入框底部492px；这是视口模拟，不代替iOS/Android真机键盘测试。
- 320×740：无横向溢出，四个顶栏按钮右边297px（页面宽305px），输入框281×64，底边728px。
- 桌面1440×900：默认/半屏均x=352.5、y=820、w=720、h=64，位置和尺寸一致。
