# 历次界面补充记录

以下为开发过程中的历史决策，冲突项以DESIGN_SYSTEM.md当前实施约定为准。

> 2026-10-18 分类页补充决策：分类内隐藏顶部双导航，固定“返回 / 当前分类名 / 搜索”标题栏；其下展示当前分类内容摘要，知识卡片加白底并显示来源平台。首页和Skill页继续保留固定双导航。此条覆盖下文“始终显示双导航”的旧约定。

> 2026-10-18 用户最新设计决策：全项目界面图标统一采用 ByteDance IconPark，替代下文原先的 Lucide 建议。分类卡片采用“前景主题图标卡 + 后方真实收藏封面”的轻量堆叠形式，替代原2×2拼贴；保留两列移动布局、柔和低饱和色与现有设计 Tokens。顶部「知识库 / 我的 Skill」始终保持在屏幕顶端，页面其余内容滚动，底部全局 AI 入口继续固定。后续实施以上述最新决策为准。

> 2026-10-18 首页布局补充：未分类知识栏在上，AI整理与重复提醒合为一张功能卡，下方为全部分类；新建文件夹位于全部分类右侧。用户星星IP透明资源用于AI整理卡装饰，不替代IconPark通用操作图标。

> 首页AI整理卡补充：紧凑三段式（左IP / 中间识别结果文案 / 右独立整理按钮）。手机约96px高、桌面104px；灰绿→暖白→极浅绿渐变降低与IP同色融合。文案依据真实重复建议、未分类数量或默认引导显示，不把规则结果宣称为模型识别。

> 最新首页微调：未分类与AI整理两栏统一76px高；AI整理无描边，仅暖白→浅绿渐变，覆盖此前灰绿渐变约定。未分类去除副文案，数量紧邻标题。演示空间从既有收藏移入3条未分类示例，不新增重复数据，后续用户归类不被启动重置。

> 文件夹卡最新样式：后方白色底卡、中间最多三张当前分类的真实收藏封面、前方浅色文件夹面板。面板集中展示IconPark主题图标、分类名和数量。此条覆盖此前两封面与独立前景图标卡的样式；空分类不借用其他分类封面。

> 文件夹视觉修整：前面板高度约占卡片52%，增加底卡/封面/面板的柔和分层阴影。图标不加背景，采用分类色系的深色，图标容器及SVG保持1:1；箭头手机22px、桌面26px（320px窄屏20px）。

> 文件夹比例补充：封面统一4:3横向比例，以object-fit:cover等比裁剪，不拉伸原图；三张封面扩大横向宽度，减小旋转角度并调整错位。图标至文字间距手机13px、桌面18px、320px窄屏8px，卡片整体略微变矮。

> 全局AI入口最新交互：默认无左侧图标的胶囊输入框，发送箭头内置；点击后自下而上展开面板，不立即弹键盘，输入框在默认/半屏/全屏保持同一底部锚点及宽度。面板保留历史/新对话/全屏/关闭，顶部手柄支持拖动及键盘调节；欢迎区使用用户星星IP，快捷提问统一中性色。
