# 界面收敛与视觉规范落地

2026-10-18，依据用户的五张界面示意和 `DESIGN_SYSTEM.md`。

## 保留的产品结构
- 知识库 / 我的 Skill 顶部导航。
- 全局底部 AI 入口、默认半屏、主动展开全屏、连续对话通道。
- 主题分类 → 知识卡片；示意图的“子文件夹”对应主题分类详情，没有增加第三层目录。
- 所有 Skill 创建入口复用对话；未增加创建表单。

## 信息取舍
| 界面 | 保留 | 移除或按需展开 |
|---|---|---|
| 知识库首页 | 分类总数、AI整理、双列分类拼贴、搜索/导入图标 | 大横幅、英文眉题、重复页面标题、宣传段落、页尾技术状态 |
| 分类详情 | 返回/标题、概括入口、内容类型、双列收藏、上下文AI入口 | 分类概括没有生成前只显示操作入口，不伪造摘要；详情不重复全套导航 |
| AI对话 | 标题、历史/新对话/展开/关闭、快捷提问、输入、必要错误提示 | 多段首次引导、重复助手名称、底部口号；不添加截图中的预设旅游回答 |
| Skill列表 | 主题筛选、新建、能力图标、名称、用途、关联收藏 | 大说明卡、重复标题；不添加无依据的“已生成/可使用”徽标 |
| Skill详情 | 能力与用途、关联数/更新时间、开始入口、来源 | 完整定义折叠；不显示未记录的使用次数；无真实封面则不造旅游头图 |

## 视觉实现
- 品牌改用“藏点本事”，英文 favtoskill；书签折角标记由 SVG 实现。
- 暖白/白色内容容器、深墨文字、有限青柠绿强调；颜色、间距、圆角和动效变量集中于 styles.css。
- 独立复用 CategoryCard / CollectionCard / SkillCard，源内容图片不足时采用文字封面，不用随机照片冒充收藏。
- 正文14px，来源12px；图标操作44px，主操作48px；16px输入避免手机聚焦缩放。
- 手机分类/收藏两列、Skill单列；PC分类/收藏四列、Skill两列；详情限宽。
- 保留 Safe Area、VisualViewport 高度适配、fixed-body 锁滚动、焦点管理。

## 可检查的入口
真实模式：`http://127.0.0.1:5173/#knowledge`，继续读取 SQLite，不预置数据。

开发布局示例：`http://127.0.0.1:5173/?preview=design#knowledge`。页面顶部明确标注“非真实收藏与 Skill”，可点击分类、卡片与 Skill 检查详情。示例不写入数据库、不发送给 AI、不提供伪造模型答案；生产构建不启用此入口。

示例只验证内容布局，不等于采集/RAG/Skill生成已完成。导入、试运行、导出仍明确提示尚未接入。

## 验证
- 390×844：分类首页、分类详情、Skill列表/详情、AI半屏/全屏已实际浏览；没有横向溢出。
- 1440×900：内容限宽1120px，分类四列，页面无横向溢出。
- 聚焦输入后缩小到390×480模拟键盘：面板480px，输入区域底部471px；仍可发送，模型未配置时显示真实后端错误且保留文字。
- 真实模式仍返回空知识库；示例与真实模式相互独立。
- `npm run build` 与 `npm test` 均已通过；真机键盘/Safe Area、真实图片与长回答来源卡仍需后续数据联调验证。
- 320px 窄屏检查无横向溢出；对话工具栏四个按钮均为44×44px。
