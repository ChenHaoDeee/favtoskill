## 模块计划
| 顺序/模块 | 实施与验收 | 正常、加载、空、异常 |
|---|---|---|
| 1 项目初始化与设计系统 | 本轮：字体/色彩/按钮/布局、双页面、对话面板、共享实体；构建通过，手机/桌面可用 | 正常页面；连接中；真实空库；API 离线可重试 |
| 2 知识库及分类 | 分类进入/新增/调整、知识详情、原文与摘要分离、管理确认；刷新后数据不丢失 | 分类/详情；读取中；空分类；失效来源/保存失败 |
| 3 采集/解析/分类 | 文字、截图、合法可访问链接；真实多模态识别，已有分类优先、默认保存、分类修正、撤回；用新内容验收 | 接收/解析/保存；空输入；片段、重复、解析/保存失败、服务未配置 |
| 4 AI 深度整理 | 数据驱动方案、修改预览、确认应用、取消/撤回；先解决 D1 子分类冲突 | 处理中；待确认方案；无需整理；版本冲突/失败回滚 |
| 5 全局 AI / RAG | 意图检索、分块/向量、原文来源、追问/新对话/历史；收藏外问题不冒充有来源 | 生成/检索中；首次进入/无相关结果；片段提示、请求失败重试 |
| 6 Skill | 统一对话澄清/选引用/生成/预览编辑/试运行/保存/导出；真实新任务走通；确认导出目标 | 各步骤状态；空 Skill/无来源；外部依赖不足、生成/导出失败 |
| 7 智能唤醒 | 重复知识/Skill 更新/闲置回顾，有依据且可忽略关闭；确认意图信号/阈值/频控 | 低打扰候选；分析中；无建议；行为数据不足不推荐 |
| 8 联调/部署 | 全链路、数据隔离、限流、备份恢复、HTTPS、REDcowork 外部 API 验证；实际访问部署结果 | 加载/成功/空/失败端到端；断网/超时/权限/配额测试 |
