# 真实 AI 配置与验收

当前交付范围：预置收藏资料 + 真实模型核心流程。链接解析 / TikHub 接入继续暂缓。

## 配置

1. 在服务端项目根目录 `.env` 中填写（不要在前端设置密钥）：

```dotenv
AI_API_KEY=你的服务商密钥
AI_BASE_URL=服务商的OpenAI兼容API根地址（通常以/v1结尾）
AI_MODEL=服务商实际支持的模型名称
```

`AI_BASE_URL` 需要 HTTPS，支持 `/chat/completions`；模型需要支持按指令输出 JSON。模型名必须与该服务商账号权限一致。仅填写配置不代表连通成功。

2. 重启后端：`npm run dev` 同时启动前后端；已启动时重启 API 进程使环境变量生效。
3. 在首页或 Skill 列表顶部点击「AI 连接」，刷新配置并检测模型连接。检测只发一条简短请求，不发送收藏资料，可能产生少量 API 费用。
4. 演示库现在默认「真实 AI」；预设资料也会实际调用模型。需要无网络展示时，可手动选择「离线演示（不调用模型）」，未配置或失败不会自动退回规则模式。

## 可选语义检索

```dotenv
AI_EMBEDDING_MODEL=服务商支持的向量模型
AI_EMBEDDING_BASE_URL=向量API根地址
AI_EMBEDDING_API_KEY=向量服务商密钥
```

向量服务支持独立的 `AI_EMBEDDING_API_KEY`。只有向量与对话的 API 根地址完全相同时，才允许省略它并沿用 `AI_API_KEY`；不同平台必须分别配置，防止密钥发错平台。未配置时使用原文分块关键词检索，仍可完成 RAG。配置后，问答和 Skill 来源推荐均使用关键词与语义检索；向量失败明确报错。首次检索会生成并缓存资料向量。

## 核心流程验收

- 基于预置资料提问，查看实际答案和引用来源，连续追问。
- 将回答转换为 Skill，沿用对话上下文与引用，确认/修改任务目标与来源。
- 生成后编辑名称、场景、输入、步骤、输出、限制与外部依赖；自然语言调整时传入当前草稿，保留未要求变更的内容。
- 文本任务真实试运行；有外部工具依赖的任务明确阻止执行。
- 保存后刷新仍存在；导出 Markdown / JSON 并检查原文引用。外部工具兼容性仍未验证。
- AI 整理预览后确认应用，撤回；无建议时不修改数据。
- 测试错误密钥、不可用模型和无相关收藏，确认不产生虚假成功或写入无依据记录。

## 已知限制

当前是本机单用户演示，未做公网鉴权。没有配置真实密钥时，不能完成在线模型效果验收。自动化测试使用隔离的 SQLite 与模拟服务商 HTTP 返回，验证调用和数据流程，不等于真实模型评测。分类顶部是资料概览，完整 AI 概括通过对话完成；超过单次检索范围时会明确说明抽样资料数量。链接导入、原生采集、复杂分类合并与外部 Skill 兼容不在本轮交付范围。
